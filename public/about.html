Аналітика та історія

Збереження історичних даних для аналізу, прогнозування та масштабування на IoT-мережі майбутнього.

Компоненти системи

Hardware

  • ESP32 або сумісний контролер для збору даних
  • Система стабілізації напруги для безпечної роботи
  • Датчики освітлення та заряду батареї
  • 3D-друкований корпус для компактності та захисту

Software

  • Node.js (Express) для обробки даних та API
  • PostgreSQL для зберігання історії та аналітики
  • Frontend на HTML, CSS, JS з неоновим дизайном
  • AI-алгоритми прогнозування та оптимізації
